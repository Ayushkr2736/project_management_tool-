# 🚀 Project Management Tool

A full-stack collaborative project management application built with the MERN stack.  
It provides real-time task updates, team collaboration features, and a modern, responsive UI for managing projects efficiently.

---

## ✨ Features

### 🔐 Authentication
- User signup & login  
- JWT-based authentication  
- Secure protected routes  

### 📁 Project & Task Management
- Create, update, and delete projects  
- Add tasks with priority, deadlines, and status  
- Kanban board–style workflow  
- Assign tasks to users  
- Track project progress visually  

### ⚡ Real-Time Collaboration
- Real-time task updates using Socket.io  
- Live project activity indicators  
- Instant sync across all connected users  

### 💬 Communication
- In-project chat  
- Real-time messaging  
- Online/offline user status  

### 🔔 Notifications
- Real-time task alerts  
- Project updates  
- Assigned task notifications  

### 🎨 Modern UI/UX
- Fully responsive design  
- Clean dashboard  
- Dark/light mode ready (optional)  
- Smooth animations & optimized layout  

---

## 🛠 Tech Stack

### **Frontend**
- React.js  
- Vite  
- Redux Toolkit  
- React Router  
- Tailwind CSS  
- Axios  

### **Backend**
- Node.js  
- Express.js  
- MongoDB + Mongoose  
- Socket.io (real-time communication)  
- JWT authentication  
- Dotenv
